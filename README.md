# 🤖 Weekly SWEA Picker

매주 월요일 오전 7시(KST)에 **SWEA D2~D4 난이도 문제 중 3개를 랜덤으로 선정**하여 Mattermost 알고리즘 스터디 채널에 자동으로 공지하는 봇입니다.

SWEA **IM 대비 알고리즘 스터디**에서 매주 문제를 직접 선정하는 번거로움을 줄이고, 꾸준히 문제를 풀 수 있도록 제작했습니다.

---

## 🎯 스터디 목적

* SWEA IM 대비
* 알고리즘 문제 풀이 습관 형성
* 다양한 문제 유형 경험
* 문제를 직접 읽고 풀이 방법을 생각하는 능력 향상
* 매주 꾸준히 3문제 풀이

---

## 🤖 주요 기능

* SWEA **D2~D4** 난이도 문제를 대상으로 문제 선정
* 약 **180개의 문제 후보** 중 매주 **3문제 랜덤 추천**
* Mattermost 알고리즘 스터디 채널에 Markdown 형식으로 자동 공지
* GitHub Actions를 이용해 **매주 월요일 오전 7시(KST)** 자동 실행
* 이미 봇이 추천한 문제는 다시 추천하지 않도록 **중복 제거**
* 추천한 문제의 이력을 `history.json`에 저장
* GitHub Actions 실행 후 변경된 추천 이력을 자동으로 GitHub에 커밋 및 Push

---

## 📌 문제 추천 방식

매주 약 180개의 문제 후보 중 아직 추천되지 않은 문제를 기준으로 **3문제**를 랜덤 선정합니다.

```text
약 180개 문제
      ↓
이미 추천된 문제 제외
      ↓
남은 문제 중 랜덤 선정
      ↓
3문제 추천
      ↓
Mattermost 자동 공지
      ↓
history.json에 추천 이력 저장
```

### 🔄 중복 추천 방지

**봇이 이전에 추천했던 문제는 다시 추천하지 않습니다.**

추천된 문제의 ID는 `history.json`에 기록되며, 다음 주 문제를 선정할 때 이미 추천된 문제를 자동으로 제외합니다.

단, **스터디원이 과거에 개인적으로 풀었던 문제까지 자동으로 확인할 수는 없습니다.**

따라서 이미 풀어본 문제가 추천되었다면 **채널에서 빠르게 알려주세요.**

예시:

> "이번 주 2번 문제는 이미 풀었습니다!"

## 📚 난이도별 문제 풀이 기준

### 🟢 D2

**무조건 도전합니다.**

IM 대비에 필요한 기본적인 구현 및 문제 해결 능력을 기르기 위한 문제이므로 적극적으로 풀어주세요.

### 🟡 D3

**무조건 도전합니다.**

D2와 마찬가지로 IM 대비를 위해 반드시 도전하는 것을 원칙으로 합니다.

### 🔴 D4

**본인의 실력에 따라 도전합니다.**

D4가 충분히 풀 수 있는 난이도라고 판단된다면 도전해주세요.

반대로 문제를 확인했을 때

> "현재 실력으로는 너무 어렵다."

라고 판단된다면 D4를 억지로 풀 필요는 없습니다.

대신 **D2~D3 중 본인이 풀 수 있는 다른 문제를 선택해서 진행합니다.**

## 🔥 가장 중요한 규칙

### 매주 최종적으로 3문제를 풉니다.

추천된 문제의 난이도가 모두 같을 필요는 없습니다.

예를 들어:

| 추천 | 풀이                          |
| -- | --------------------------- |
| D2 | ✅ 도전                        |
| D3 | ✅ 도전                        |
| D4 | ❌ 너무 어려움 → D2/D3 중 다른 문제 선택 |

즉,

**D2 + D3는 무조건 도전하고, D4는 가능한 경우 도전하되, 어려운 경우 D2~D3 문제로 대체하여 매주 3문제를 채우는 것**을 원칙으로 합니다.

## 🗓️ 자동 실행 일정

GitHub Actions를 이용하여 **매주 월요일 오전 7시(KST)**에 자동으로 실행됩니다.

```text
매주 월요일 07:00 KST
        ↓
GitHub Actions 실행
        ↓
문제 후보 목록 불러오기
        ↓
기존 추천 문제 확인
        ↓
중복 문제 제외
        ↓
랜덤으로 3문제 선정
        ↓
Mattermost에 자동 공지
        ↓
추천 이력 저장
        ↓
GitHub에 history.json 커밋
```

또한 `workflow_dispatch`를 사용하여 GitHub Actions에서 **수동 실행 및 테스트**도 가능합니다.

## 🔐 보안

Mattermost Incoming Webhook URL과 같은 민감한 정보는 **절대 GitHub 저장소에 직접 업로드하지 않습니다.**

GitHub Repository의:

```text
Settings
→ Secrets and variables
→ Actions
→ New repository secret
```

에서 다음 이름으로 등록합니다.

```text
MATTERMOST_WEBHOOK_URL
```

GitHub Actions에서는 Secret을 환경 변수로 전달하여 사용합니다.

```yaml
env:
  MATTERMOST_WEBHOOK_URL: ${{ secrets.MATTERMOST_WEBHOOK_URL }}
```

Webhook URL은 다음과 같은 이유로 코드에 직접 작성하지 않습니다.

* GitHub에 공개될 위험 방지
* Webhook URL 유출 방지
* 저장소를 공유하더라도 민감한 정보 보호

## 📝 문제 목록 관리

`swea_problems.json`에는 추천 대상이 되는 SWEA 문제 목록이 저장되어 있습니다.

문제를 추가하거나 삭제할 경우 해당 JSON 파일을 수정하면 됩니다.

`history.json`에는 봇이 지금까지 추천한 문제의 이력이 저장됩니다.

처음 프로젝트를 실행할 때는 다음과 같이 시작합니다.

```json
{
  "sent_ids": []
}
```

이후 봇이 문제를 추천할 때마다 추천된 문제 ID가 자동으로 기록됩니다.
